# 🎤 Guide de Présentation - Jury

## ⏱️ Timing (15 minutes)

### 1. Introduction (2 min)
**"Bonjour, je m'appelle [Nom] et je vais vous présenter Eco-Refill AI Station."**

Points clés :
- 87% des Français attendent que les marques réduisent le plastique
- Les solutions de recharge actuelles sont peu pratiques
- Notre solution combine **bornes intelligentes** + **IA** + **gamification**

### 2. Démonstration App (5 min)
**"Laissez-moi vous montrer comment ça fonctionne..."**

#### Étape 1 : Welcome Screen
- "Voici l'écran d'accueil qui présente le concept"
- Montrer les 4 features principales
- Statistiques Dove (20 500 tonnes plastique économisées)

#### Étape 2 : Questionnaire
- "L'utilisateur répond à 5 questions personnalisées"
- Exemple : Type de peau → Environnement → Produits → Besoins
- "Cela prend seulement 2 minutes"

#### Étape 3 : Product Matching
- "L'algorithme calcule un score de match pour chaque produit"
- Démontrer le swipe (style Tinder)
- "L'utilisateur swipe à droite s'il aime, à gauche pour passer"
- Montrer le score de matching (80-100% = Match Parfait)

#### Étape 4 : QR Code
- "Un QR code unique est généré"
- "Il encode le profil + produits sélectionnés"
- "Utilisable à la borne avec un simple scan"
- Montrer l'aperçu d'impact mensuel

#### Étape 5 : Dashboard
- "L'utilisateur suit son impact en temps réel"
- Montrer : CO₂ évité, plastique économisé, bouteilles sauvées
- Système de badges pour engagement

### 3. Innovation Technologique (3 min)

#### Algorithme IA
```
"Notre algorithme calcule un score sur 4 critères :"
- Type de peau (40%) → Correspondance directe
- Environnement (20%) → Pollution, UV, humidité
- Catégories (20%) → Préférences produits
- Besoins (20%) → Hydratation, volume, etc.

"Résultat : 85-95% de satisfaction utilisateur projetée"
```

#### Data pour Unilever
```
"Chaque scan collecte des données anonymisées :"
- Fréquence de recharge par zone
- Produits les plus demandés
- Tendances par démographie
- Prédiction de réassort

"Ces insights sont exclusifs et exploitables pour R&D"
```

## 🤔 Questions Fréquentes & Réponses

### Q1 : "Pourquoi les gens utiliseraient ça vs acheter en magasin ?"
**R :** 
- **Économie** : 10-20% moins cher (pas d'emballage)
- **Écologie** : Impact visible et mesurable
- **Pratique** : Bornes proches (campus, salle sport)
- **Personnalisation** : Produits vraiment adaptés

### Q2 : "Comment garantir l'hygiène des recharges ?"
**R :**
- Distributeurs hermétiques
- Nettoyage automatique après chaque utilisation
- Certification ISO normes cosmétiques
- Traçabilité complète (date remplissage, lot)

### Q3 : "Et si quelqu'un partage son QR code ?"
**R :**
- QR code lié à profil unique
- Historique des recharges tracé
- Détection utilisation anormale
- Option authentification biométrique (V2)

### Q4 : "Coût d'installation d'une borne ?"
**R :**
- **Prototype MVP** : 15k€ (développement carton + électronique)
- **Borne production** : 8-10k€ unitaire
- **Maintenance** : 100€/mois (nettoyage + réassort)
- **Amortissement** : 2-3 ans

### Q5 : "Pourquoi pas juste une app sans borne ?"
**R :**
- L'app **accompagne** l'expérience borne
- Borne = moment d'achat physique (besoin réel)
- Combinaison **digital + physique** = meilleur engagement
- Impossible de recharger sans infrastructure

### Q6 : "Concurrence avec Loop, TerraCycle ?"
**R :**
- Loop = consigne à domicile (logistique complexe)
- TerraCycle = recyclage, pas recharge
- **Nous** = vrac intelligent localisé + IA
- Complémentaires plutôt que concurrents

### Q7 : "Scalabilité internationale ?"
**R :**
- App multilingue (facile)
- Adapter catalogue produits par pays
- Partenariats distributeurs locaux
- Expansion Europe puis US/Asie

## 🎬 Tips de Présentation

### Avant la Présentation
- [ ] Tester l'app sur votre téléphone
- [ ] Préparer des screenshots de backup
- [ ] Avoir le QR code Expo prêt pour démo live
- [ ] Timer vos sections (2-5-3-3-1-1)
- [ ] Répéter devant un miroir

### Pendant la Présentation
- ✅ **Parler clairement** et pas trop vite
- ✅ **Regarder le jury** dans les yeux
- ✅ **Montrer l'app en live** (plus impactant que slides)
- ✅ **Utiliser les chiffres** pour crédibilité
- ✅ **Sourire** et montrer votre passion

### Gestion du Stress
- Respirez profondément avant de commencer
- Si bug technique : restez calme, utilisez screenshots
- Si question difficile : "Excellente question, laissez-moi réfléchir..."
- Transformez critiques en opportunités d'amélioration

### Clôture
- Terminez sur note positive et énergique
- Remerciez le jury de leur attention
- Invitez-les à tester l'app eux-mêmes
